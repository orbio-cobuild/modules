# @cofounder/modules

Tested building blocks for apps generated by Cofounder: wallet and Orbio sign-in, payments and tips, token gating, swaps, on-chain verification, background jobs, notifications, an agent loop and an agent API.

Generated apps install this package instead of carrying a copy of every module's code. That keeps each app's own source small enough to deploy in one upload.

## How apps use it

An app depends on one exact release:

```json
"@cofounder/modules": "https://github.com/orbio-cobuild/modules/releases/download/v0.1.0/cofounder-modules-0.1.0.tgz"
```

The package is TypeScript source for Next.js 16 (App Router, webpack). The app's template wires it in:

- `next.config.ts` adds `transpilePackages: ['@cofounder/modules']` and resolves `@/` to the app's `src/` first, then to this package's `src/`.
- `tsconfig.json` has the same order: `"@/*": ["./src/*", "./node_modules/@cofounder/modules/src/*"]`.
- The app's CSS adds `@source "../../node_modules/@cofounder/modules/src"` so Tailwind sees the components' classes.

So module code and app code both import `@/lib/payments/...`, `@/components/payments/...` and so on, and a file in the app always wins over the package's. Routes and pages (`src/app/**`), module settings (`src/config/**`) and anything filled in per app stay in the app.

`modules.json` lists every module in the package, its version and its files.

The package has no dependencies of its own. The app installs the npm packages each module needs (next, react, viem, wagmi, zod, jose, @supabase/supabase-js…) at pinned versions.

## Secrets

This package holds code only. It contains no keys, tokens or passwords. Every secret an app needs (session secrets, server keys, bot tokens) is read from that app's own environment variables.

## Releases

Each version is a git tag `vX.Y.Z` here. Pushing a tag runs `.github/workflows/release.yml`, which checks the tag matches `package.json`, packs the tarball and publishes it, with its SHA-256, as a GitHub release. A published version is never replaced; changes get a new version.

The source is generated from the Cofounder monorepo, so changes made directly here are overwritten by the next release.
